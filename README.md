A tiny stack VM interpreter in TypeScript — runs all 40 ISA programs from /input and writes stdout + exit code to /output. Practice score 1,000,000/1,000,000, above the 670,000 house baseline.

## Run it

```sh
node main.ts
```

The program reads `/input/<id>/program.bin` + `input.bin` for each instance and writes `/output/<id>/stdout.bin` + `exit.txt`.
